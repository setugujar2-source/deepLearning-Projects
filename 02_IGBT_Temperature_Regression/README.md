# 基于一维CNN与特征工程的IGBT结温预测

## 项目简介
模拟电力电子器件测试场景，构建一维CNN回归模型，通过易测量的电参数（Vce、Ic、壳温）预测IGBT的结温。

## 核心技术
- **深度特征工程**：分析物理规律，创建 `Power = Vce * Ic` 特征，解决了多特征输入下的模型欠拟合/过拟合问题。
- **防止过拟合**：引入 `EarlyStopping` 早停机制，监控验证集损失，连续N轮不下降便自动停止训练。
- **模型轻量化**：采用极简的线性模型，将参数从705个精简至5个，极大提升了泛化能力。
- **数据归一化**：使用 `MinMaxScaler` 对输入和输出进行归一化处理。

## 运行结果
经过多轮调试与优化，测试集 **平均绝对误差（MAE）降至 1.21 摄氏度**，预测曲线与真实值高度重合。

## 如何运行
1. 配置 Python 环境，安装 `tensorflow`、`numpy`、`pandas`、`matplotlib`、`scikit-learn`。
2. 运行 `IGBT_Temp_Regression.ipynb` 文件，即可复现模型训练与预测对比图。
